## Optional local setup

Run these commands in your terminal:

```bash
python -m venv .venv
source .venv/bin/activate
pip install jupyter
jupyter notebook
```

On Windows, activate with `.venv\Scripts\activate` instead.

The logging notebook uses printed labels to introduce log messages.
The tool wrapper uses clearly labelled sample weather instead of a live API.
